## Описание проекта

ENU Көмек — двуязычный ИИ-помощник для студентов Евразийского национального университета имени Л.Н. Гумилёва. Помогает находить информацию в университетских документах и разбираться в процедурах академической мобильности, тестирования и обучения. В режиме работы с документами система ищет подтверждающие фрагменты, показывает ответ и ссылки на страницы PDF или разделы DOCX. При недостатке подтверждений сообщает об отсутствии информации. Предусмотрены история диалога, уточняющие вопросы, просмотр оригиналов, поиск по библиотеке и сохранение ответов. Интерфейс доступен на казахском и русском языках. Реализован локальный MVP с базой из 19 документов, включая распознанные сканированные правила учебного процесса.

## Решаемая проблема / значимость для университета

Проект направлен на упрощение поиска информации, распределённой между университетскими инструкциями и документами. Студент может задать вопрос обычным языком и проверить ответ по первоисточнику. Ожидаемая польза — более понятная навигация по процедурам и снижение количества повторяющихся справочных обращений; этот эффект требует проверки в пилоте. Для будущего подключения к SMART.ENU предусмотрен JSON API. Реальное подключение к университетским аккаунтам и системам пока не выполнено.

## Использованные ИИ-технологии, инструменты и языки программирования

Python, JavaScript, HTML, CSS. Поиск по документам: TF-IDF, латентно-семантический анализ LSA/TruncatedSVD и косинусная близость на базе scikit-learn. Формирование ответов: RAG — языковая модель получает найденные фрагменты и формирует ответ со ссылками; для отдельных требований используются точные краткие цитаты. Поддерживаются локальная Qwen 2.5 3B через Ollama и Google Gemini API. Добавлены адаптеры OpenAI Responses API и Anthropic Messages API; их работа с реальными аккаунтами требует соответствующих ключей. Обработка PDF/DOCX: pypdf, Poppler, стандартные библиотеки Python; OCR: Tesseract с казахскими и русскими языковыми данными. Реализованы отдельное хранение ключей провайдеров на сервере и разрешения на передачу документов облачным моделям. Проверка ссылок программная и не гарантирует фактическую правильность каждого утверждения модели.
