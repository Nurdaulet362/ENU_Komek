# Демонстрация обновлённого ENU Көмек

1. Запустить Ollama и приложение. Дождаться индикатора локальной ИИ-модели.
2. Выбрать «Свободный разговор», написать «Привет! Объясни, что такое MVP». Показать ответ и отметку, что он не проверен по документам ЕНУ.
3. Переключить «Документы ЕНУ», спросить о документах для возвращения с академической мобильности. Показать краткий ответ с цитатами и раскрыть источники.
4. Задать «А что делать дальше?» — показать сохранённую ленту и контекст темы.
5. Открыть страницу PDF, содержащую требование о транскрипте.
6. Спросить стоимость общежития в 2026 году — показать отсутствие подтверждения.
7. Переключить язык — шаблонное сообщение должно перевестись, оригинальная цитата остаётся на исходном языке.

Тип продукта: локальный диалоговый ИИ-помощник с RAG. Поиск TF-IDF + LSA, генерация Qwen 2.5 3B через Ollama. Это MVP без подключения к студенческим аккаунтам и реальному API SMART.ENU.

Не заявлять о безошибочности: проверка формата ссылок не подтверждает каждое утверждение. OCR требует сверки. Не выдавать результаты шести поисковых сценариев за общую точность модели.
